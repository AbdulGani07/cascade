# Support

Use the appropriate public channel for non-sensitive help:

- GitHub Issues for reproducible bugs and accepted work proposals.
- GitHub Discussions, once enabled by an owner, for questions, ideas, usage help, and showcases.
- Existing documentation, especially [Getting started](docs/GETTING_STARTED.md),
  [FAQ](docs/FAQ.md), and [Troubleshooting](docs/TROUBLESHOOTING.md), before opening a thread.

Provide the Cascade version or commit, operating system, Node.js version, command, minimal fixture,
expected result, and redacted output. Do not upload proprietary source or secrets.

Maintainers respond as capacity permits. Community support has no guaranteed service level.
Security vulnerabilities must use the private process in [SECURITY.md](SECURITY.md), never a public
issue or Discussion.
