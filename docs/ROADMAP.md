# Roadmap

Cascade’s roadmap is evidence-led and does not promise release dates.

## Current directions

- Improve resolution precision for supported ecosystems without executing repository code.
- Extend incremental analysis and cache invalidation coverage.
- Improve aggregation and virtualization for very large dashboard graphs.
- Strengthen plugin isolation and trust-boundary tooling.
- Publish and version configuration and report schemas more explicitly.
- Add stable performance thresholds only where CI variance permits meaningful signals.
- Expand regression fixtures for polyglot and adversarial repositories.

## Selection principles

Work is prioritized by measured user impact, correctness, security, maintainability, and reproducible benchmarks. New language claims require fixtures and tests at the capability level being documented.

Use GitHub issues for proposals. A roadmap item is not a commitment until it is assigned to a release milestone by maintainers.
